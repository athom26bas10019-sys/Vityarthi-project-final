# Office Management System - Project Statement

## 1. Problem Statement

With the manual maintenance of employee's database, it becomes tedious to

add,

search,

update and

maintain the employee's records.

The Office Management System is a simple Python program which

provides a basic set of menus to manage employee's records.

It provides features like storing employee's details, searching an employee, updating the details of the employees, delete an employee, mark attendance, marking leaves and calculating the salary.

## 2. Scope Of The Project

Scope of the project is limited to the basic record management of an employee in a small office.

The system is capable of:

-  Storing the employee id, employee name, department, designation and basic salary.

-  Displaying the employee's detail.

-  Searching the employee by the employee id.

-  Updating the details of the employee.

-  Deleting the employee.

-  Marking attendance of the employee.

-  Recording the number of leaves taken by an employee.

-  Calculating the HRA, DA, gross salary, tax, and net salary of an employee.

-  Providing a simple menu to access the above features.

The project is a simple console based application and is capable of persisting the employee's information during the execution of the program.

## 3. Target Users

Following are the potential users of the system:

-  Staff of the small office.

-  Office administrator.

-  Beginner level employees willing to learn employee record management.

-  Students willing to learn Python language.

-  Users who needs simple console based employee record management system.

## 4. High level features

### Employee Management

-  Add employee

-  Display employee

-  Search employee

-  Update employee

-  Delete employee

### Attendance And Leave

-  Mark attendance of an employee

-  Apply on leave by providing the number of leave days

### Salary Management

-  Storing the basic salary of the employee

-  Calculating the HRA as 20% of the basic salary

-  Calculating the DA as 10% of the basic salary

-  Calculating the gross salary

-  Calculating the tax as 10% of the gross salary

-  Calculating the net salary

### User Interface

-  Menu driven console application

-  Options are labeled from 1 to 9.

-  Interaction with the application is done through simple input statements.

-  Application provides success message whenever an update, search or delete operation is done successfully.

-  Providing appropriate messages for invalid entries, no records found, invalid option chosen and invalid update option.

### Validation

-  Validating the input salary is a valid number.

-  Validating leave days as a valid number.

-  Handling the no employee found scenario.

-  Handling the invalid menu option and invalid update scenario.
